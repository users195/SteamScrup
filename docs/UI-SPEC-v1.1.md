# SteamScrup v1.1 UI 设计规范（对齐 LightC）

| 项目 | 内容 |
|---|---|
| 参考项目 | [LightC](https://www.lightc.app/zh-CN/) —— Tauri + React + Tailwind 的 C 盘清理工具 |
| 技术差异 | 参考为 Web UI；本项目为 **WPF / XAML**，无 Tailwind，样式靠 `ResourceDictionary` + `ControlTemplate` 手工实现 |
| 主色 | 浅色主题 `#2A7FB8`，深色主题 `#66C0F4` |
| 图标 | Windows 自带图标字体，**零依赖** |
| 窗口边框 | 系统标准标题栏（不自绘） |
| 启动行为 | 保持自动扫描 |

---

## 1. 从参考项目提取的设计语言

| 特征 | 参考做法 | 我们的落地 |
|---|---|---|
| 结构 | 顶部状态条 + 左侧栏 + 右侧单列卡片流 | 同结构（见 §3） |
| 卡片 | 圆角 ~12px、极淡边框、柔和阴影、大留白 | `Border` + `DropShadowEffect`，圆角 10–12 |
| 强调色 | 单一绿色，只用在主按钮和进度条 | 单一浅蓝，**只用在主按钮、选中态、进度条、图表高亮** |
| 底色 | 白卡 + 极浅灰底 | 浅色 `#F4F6F8` 底 / 白卡；深色 `#14181D` 底 / `#1B2028` 卡 |
| 层次 | 大标题 + 灰色副标题 + 小字状态标签 | 沿用现有 `H1` / `Caption` / `Muted` 三级 |
| 标签 | 圆角药丸 chip（带色底） | 风险等级 chip 已有，统一圆角与内边距 |
| 开关 | 药丸 toggle | 已有 `SwitchToggle`，微调尺寸 |
| 按钮 | 大号主按钮、圆角、白字 | `PrimaryButton` 加大内边距至圆角 8、高度 36 |
| 动画 | framer-motion 弹性过渡 | **不做**（WPF 仅简单淡入，不作为验收项） |

## 3. 布局

```
┌──────────────────────────────────────────────────────────────────┐
│ ① 顶部状态条                                                       │
│  [图标] 磁盘占用进度条 + 已选大小     [重新扫描] [清理所选]           │
├────────────┬─────────────────────────────────────────────────────┤
│ ② 左侧栏    │ ③ 内容区（卡片流）                                    │
│  228px     │                                                     │
│  导航项     │   候选列表：每项一张卡片                               │
│  库路径列表 │   设置页：分组卡片                                     │
│            │   总览页：指标卡 + 图表卡                              │
└────────────┴─────────────────────────────────────────────────────┘
```

### 3.1 顶部状态条（新增，对齐参考顶部）

- 左：状态图标 + Steam 运行状态文字（绿=未运行 / 黄=运行中）
- 中：**磁盘占用进度条**（两列 `Grid` 实现，见 §5 约束）+ 右侧显示"已选 X 项 / Y"
- 右：`重新扫描`（次按钮）+ `清理所选`（主按钮、蓝色）
- 进度条仅在扫描/清理中显示

### 3.2 左侧栏

- 宽度 228，`BgPanel` 底、圆角
- 导航项：图标 + 文字，选中态为 `BgSelected` 药丸 + 左侧 3px 强调色竖条（已有 `NavItem` 样式，补图标位）
- 底部：检测到的库路径列表（等宽小字）

### 3.3 候选列表 → 卡片式

每项一张卡片，替代当前的紧凑行：

```
┌────────────────────────────────────────────────────────────┐
│ ☐  [图标块]  名称（H2）                        [风险 chip]  │
│              路径（等宽小字，超长省略）                        │
│              说明文字（Muted）+ 大小 · 文件数 · 修改时间       │
└────────────────────────────────────────────────────────────┘
```

- 卡片间距 8，内边距 12,10，圆角 10
- 悬停：`BgHover`；选中（勾选）：`BgSelected` + 左侧强调色竖条
- **信息密度代价**：卡片比紧凑行占高约 1.6 倍。缓解措施：默认行高压缩（说明与元信息同一行）、保持虚拟化
- 保护项：整卡降透明度、`受保护` chip 用 `FgMuted`，复选框禁用

### 3.4 设置页

三张分组卡片：`外观`（主题/语言）、`清理行为`（删除方式/高级选项）、`路径与日志`（Steam 目录/日志目录）

### 3.5 总览页

1. 指标卡：Steam 路径 / 库数量 / 已安装游戏 / 候选条目数
2. 图表卡：饼图（左）+ 图例（右，色块·分类·大小·占比）
3. 明细卡：条形图列表，按大小降序
4. 结论行：「主要占用来自 X，共 Y（Z%）」
5. ~~安全保护说明卡~~ → 删除（Issue 7）

## 5. 约束与风险

### 5.1 硬约束（v1.0 崩溃教训，不可违反）

`ProgressBar.Value`、`TextBox.Text`、`Run.Text`、`ToggleButton.IsChecked` 的元数据
`BindsTwoWayByDefault = true`。绑到只读属性会在 `Show()` 期间抛异常导致窗口起不来。

| 场景 | 必须做法 |
|---|---|
| 进度条 | 用两列 `Grid`（`GridLength` 不被写回），**禁用 `ProgressBar`** |
| `<Run Text>` | 必须用 `{ui:OneWayText ...}` |
| 本地化索引器 | 保留忽略写入的 setter |
| 文本框 | 只绑可写属性 |
| 卡片选中态 | 用 `CheckBox.IsChecked` 绑可写 `IsSelected`，**不要**用 `ListBoxItem.IsSelected` 绑只读属性 |

**每轮 XAML 改动后必须跑**：
```
SteamScrup.exe --exit-after=10000 --binding-report=report.txt
```
退出码 `0` 且报告显示「0 告警 / TwoWay 源全可写」才算通过。

### 5.2 风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 卡片化降低信息密度 | 参考项目无高密度列表场景 | 压缩卡片高度；保留虚拟化；必要时提供"紧凑/卡片"切换 |
| 我无法预览界面 | 无头环境 | 结构一次做对；依赖用户反馈迭代 |
| 阴影性能 | 大量卡片带 `DropShadowEffect` 会掉帧 | 阴影只用于容器卡片；列表项用描边代替阴影 |
| 图标字体在旧系统缺失 | Win10 早期版本可能没有 Segoe Fluent Icons | 已设回退链，最差退到 `Segoe UI Symbol` |
| 深浅主题对比度 | 强调色在两主题下取值不同 | 已分别取 `#2A7FB8` / `#66C0F4`，白字与深字各自达标 |
